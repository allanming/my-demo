# Snake

A classic Snake game you can play in the browser. Open `index.html` — no build step, install, or server required.

## How to play

1. Open `index.html` in any modern browser.
2. Press an arrow key or **WASD**, or click **Start game**.
3. Guide the snake to the red food. Each bite grows the snake and adds 1 to your score.
4. The game ends if the snake hits a wall or its own body.
5. After game over, press **Space** or click **Play again**.

## Controls

| Action | Keys |
| --- | --- |
| Move | Arrow keys or W A S D |
| Restart after game over | Space, or the on-screen button |

The current score and session best (saved in this browser) appear above the board. The snake speeds up slightly as the score rises.

## Files

- `index.html` — page shell
- `styles.css` — layout and theme
- `game.js` — game loop, input, and canvas rendering
